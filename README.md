One status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. The sadness lives in one small, exact detail: an unfinished draft that ends mid-apology — "sorry, I" — and an agent that will never know how the sentence ends.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (76 characters, standard library only).
